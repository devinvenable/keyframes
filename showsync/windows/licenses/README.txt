Qt / PySide6 license texts
=========================

These unmodified license texts come from the Qt for Python 6.11.2 source:
https://github.com/pyside/pyside-setup/tree/v6.11.2/LICENSES

PySide6 source: https://code.qt.io/cgit/pyside/pyside-setup.git/
Qt source: https://code.qt.io/cgit/qt/qtbase.git/
Qt license information: https://doc.qt.io/qt-6/licensing.html
Qt for Python third-party notices: https://doc.qt.io/qtforpython-6/licenses.html

The Windows build additionally copies license directories supplied by installed
dependency wheels. See build-requirements.txt for exact component versions.
Qt DLLs and plugins remain separate shared libraries in _internal/PySide6.
